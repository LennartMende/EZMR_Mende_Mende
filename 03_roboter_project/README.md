The goal of this project is to implement control for a mobile robot. The robot’s ESP32 microcontroller acts as a communication node, publishing and subscribing data via micro‑ROS. Sensor data collected by the robot is transmitted to a PC, which serves as the central computational unit. The PC processes this data to generate control commands for the robot and to provide a graphical user interface (GUI).

Further goals will come up during the work on that project.
